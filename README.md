# Stream Notify Native

Тема для стандартных панелей OBS Studio 33 в цветах Stream Notify: микшер звука, сцены, источники, переходы и управление.

Тема меняет только оформление. Все кнопки и настройки OBS работают как обычно. Панели сторонних дополнений, в том числе Trula, не входят в тему.

## Установка

1. Скопируйте `Stream_Notify_Native.ovt` в `%APPDATA%\obs-studio\themes\` (создайте папку, если её нет).
2. Перезапустите OBS Studio.
3. Откройте **Настройки → Общие**: установите **Тема: Yami**, затем **Стиль: Stream Notify Native**.

Чтобы вернуться к прежнему виду, выберите прежнюю тему в настройках. Удалять файл для этого не требуется.

## Для будущего общего установщика

Установщику достаточно скопировать один файл `Stream_Notify_Native.ovt` в папку тем пользователя. Выбор темы остаётся за пользователем. Тема не зависит от Stream Chat, Stream Notify или Stream Stats: каждый плагин работает самостоятельно.

Тема основана на штатной Yami через механизм вариантов OBS. Файлы и код OBS в этот репозиторий не скопированы. Исходная тема и описание механизма: [OBS Studio Theme System](https://github.com/obsproject/obs-studio/wiki/OBS-Studio-Theme-System).
