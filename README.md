# Stream Suite OBS Theme

**Тема оформления OBS Studio 33** для стандартных панелей: микшера звука, сцен, источников, переходов и управления. Цвета подобраны в стиле наших плагинов Stream Chat, Stream Notify и Stream Stats.

Тема меняет только оформление. Все кнопки и настройки OBS работают как обычно. Панели сторонних дополнений, в том числе Trula, не входят в тему.

## Установка

1. Скопируйте `Stream_Suite_OBS_Theme.ovt` в `%APPDATA%\obs-studio\themes\` (создайте папку, если её нет).
2. Перезапустите OBS Studio.
3. Откройте **Настройки → Общие**: установите **Тема: Yami**, затем **Стиль: Stream Suite OBS Theme**.

Если вы устанавливали пробную версию `Stream_Notify_Native.ovt`, удалите её из папки тем перед перезапуском OBS.

Чтобы вернуться к прежнему виду, выберите прежнюю тему в настройках. Удалять файл для этого не требуется.

## Для будущего общего установщика

Установщику достаточно скопировать один файл `Stream_Suite_OBS_Theme.ovt` в папку тем пользователя. Выбор темы остаётся за пользователем. Тема не зависит от Stream Chat, Stream Notify или Stream Stats: каждый плагин работает самостоятельно.

Тема основана на штатной Yami через механизм вариантов OBS. Файлы и код OBS в этот репозиторий не скопированы. Исходная тема и описание механизма: [OBS Studio Theme System](https://github.com/obsproject/obs-studio/wiki/OBS-Studio-Theme-System).
